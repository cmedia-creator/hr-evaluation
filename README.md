# 人事評価システム v5 候補版

このフォルダは、本番反映前の統合候補です。

## 今回の変更

- ホーム画面を「役割別ホーム」方式へ変更
- ログインユーザーの権限（can_self / can_manage / can_executive）に応じて表示を自動切替
- 一次評価・面談後評価の未完了人数を表示
- 対象者一覧では未完了者を上部へ並べ、色で強調
- 評価の流れは常時表示せず、「流れを確認」でモーダル表示
- 面談後評価で次の条件に該当する評価項目は、項目ごとの理由コメントを必須化
  - 本人評価と面談後評価の差が2点以上
  - 一次評価と面談後評価の差が2点以上
  - 面談後評価が5または1
- 条件が複数重なってもコメントは1項目1件
- 一時保存はコメント未入力でも可能
- 提出時は必須コメント不足があれば提出不可
- 点数変更で対象外になっても保存済みコメントは保持
- 成長会議・最終評価の初期表示は「成長会議対象者のみ」
- 成長会議対象者フィルターは「対象者のみ / 全社員」
- フィルター順は「成長会議対象者 / 部署 / ステータス」
- コメントフィルターは廃止
- 成長会議の社員詳細で面談後評価コメントを確認可能

## DB前提

`evaluation_records.interview_item_comments jsonb not null default '{}'::jsonb`

キーは `item_<evaluation_item_id>`。

DB側の提出時バリデーショントリガーも別途適用済み。
