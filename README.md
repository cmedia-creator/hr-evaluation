# hr-evaluation / 営業設計DB連動版

人事評価システムの営業設計向けPoCです。

## 今回の変更

従来のJavaScript直書き5項目を廃止し、Supabaseの評価テンプレートを読み込む方式へ変更しました。

現在Supabaseには営業設計の以下3テンプレートが登録されています。

- 一般職: 59項目
- 中堅職: 59項目
- 係長主任: 59項目

評価者がログインすると、評価対象社員の部署・階層に紐づくテンプレートを自動取得します。

## 差し替え方法

このZIP内の以下4ファイルをGitHubリポジトリ `hr-evaluation` のルートへ上書きしてください。

- index.html
- style.css
- app.js
- README.md

GitHub Pagesは既に有効なら再設定不要です。
commit後、通常は少し待てば公開ページへ反映されます。

## 機能

- ID / PASSログイン
- 評価者情報取得
- 評価対象社員取得
- 部署・階層別テンプレート自動取得
- 59評価項目の自動描画
- 各項目の1〜5点評価
- 評価基準表示
- ウェイトによる加重点数自動計算（100点満点）
- 入力進捗表示
- 一時保存
- 再読込復元
- 全項目入力後の評価確定
- 確定後の画面編集停止

## 注意

現在はPoCです。実在社員の本番評価データはまだ投入しないでください。
