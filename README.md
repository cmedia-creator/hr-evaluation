# 人事評価システム v4.1 Enterprise Demo

今回のデモは、日本企業向けの業務システムらしい情報密度と安心感を重視したUIに変更しています。

## 主な機能
- 昇給 / 夏季賞与 / 冬季賞与の評価回切替
- 権限別ダッシュボード
- 自己評価
- 一次評価
- 面談後評価
- 役員用全社員一覧
- 前回評価参照
- 前回評価の全コピー
- セクション単位コピー
- 前回評価との差分表示
- item_codeによる評価項目の継続比較
- 一時保存 / 提出 / 最終確定

## UI方針
Apple風のミニマルUIではなく、日本企業のグループウェア・基幹システムに近い、
情報量が多く、役割と進捗が明確に見える「導入費用が高そうな業務システム感」を狙っています。
