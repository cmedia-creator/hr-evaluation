# hr-evaluation workflow v3

人事評価制度のワークフローを見せるためのデモ版です。

## デモで確認できること

同じ `EV0001` アカウントにデモ用として複数権限を付与しています。

- 自己評価
- 一次評価
- 面談後評価
- 役員・成長会議

本番では各社員のアカウント権限に応じて、表示されるメニューを分けます。

## 評価フロー

1. 自己評価
2. 一次評価
3. 面談後評価
4. 成長会議
5. 最終評価

## セクション別の入力権限

- ① 全社共通の成果評価：役員
- ② 共通の行動評価：本人 → 管理職 → 面談後 → 最終調整
- ③ 部署固有の成果評価：管理職 → 面談後 → 最終調整
- ④ 部署固有の能力・行動評価：本人 → 管理職 → 面談後 → 最終調整
